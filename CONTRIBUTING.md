# Contributing to Mossline

Contributions are welcome. Please open an issue before a major change and work on a focused feature branch.

- Preserve provenance and distinguish inferred from confirmed relationships.
- Keep graph-core portable and avoid vendor lock-in.
- Do not commit client datasets, credentials or personal data.
- Check image and dataset redistribution permissions.
- Add tests for graph logic, and run test/typecheck/build before merge.
