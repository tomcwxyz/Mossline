All comparison views use the exact same graph and saved positions. Zoom, pan and select nodes in each pane. The comparison reports initialisation and single-draw timings; it does not measure frame rate or memory consumption. Sigma.js v4 is loaded from a version-pinned CDN; a network connection is needed.

Gephi Lite: export GEXF, then open Gephi Lite and import the file. Cosmograph: export the two CSVs, then open Cosmograph and import the node/edge data. Cosmograph is evaluated externally because its standard licence does not permit commercial integration. These external tools will apply their own layouts unless configured to use the exported coordinates.
